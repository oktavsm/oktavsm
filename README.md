### about

- Building Android apps in **Kotlin** and **Jetpack Compose**, mostly for university and Dicoding tracks
- Developing **[agy-tern](https://github.com/oktavsm/agy-tern)**, a native Tern Surface Protocol (TSP) terminal frontend for `agy` over ACP
- Writing backends and automation tooling in TypeScript (Bun / Node.js), Python, and Laravel
- Running my own VM (`pg-bcc`): Docker, nginx, n8n, telemetry APIs, and every SVG card on this page
- Up for collaborating on Android apps, terminal UIs, or backend tooling
